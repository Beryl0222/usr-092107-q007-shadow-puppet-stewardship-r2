# 皮影剧团藏用协同台

本仓库记录该项目已确认的领域对象、事件名称和基础校验方式，便于不同系统交换一致的数据。

## 资料范围

- `contracts/domain.schema.json`：领域事件信封、聚合类型、事件名称与各事件的载荷约定。
- `data/sample.json`：一条用于本地联调的中文样例。
- `data/sample_log.json`：一次下乡演出的完整事件流样例——从物件登记、病害修缮、剧目审定、阵容确认到出入库闭环与扫码发布。
- `src/`：事件信封与业务规则的最小校验代码。
- `tests/`：验证样例与业务规则的正反对照。

## 覆盖的业务域

- **藏品**：皮影部件、材质与年代登记；病害与修缮记录，修缮前后照片只增不删（事件类型中不存在删除照片的事件）；替身道具登记并指明所替代的老物件。
- **剧目**：脚本版本审定，传统剧目与新时代改编可共用角色，但唱词来源与适用场合分别审定。
- **人员与乐器**：角色资格与伴奏资格授予；高龄艺人退出、学徒缺席、乐器故障均记为事件。
- **演出**：场地方确认日期与条件；按节目最低阵容判断能否演出（`assess_feasibility`）；开具运输清单；记录实际演出。
- **出入库**：出库登记用途与责任人，归还登记状况，每件物品闭环归还。
- **公开内容**：扫码内容经审定后发布，仅介绍技艺故事，不得包含藏品库位、未成年人资料与未公开修复细节。

## 核心规则

记录一经接收，标识、发生时间与版本不得原地改写；更正使用 `supersedes` 指向被更正记录的新事件，同一聚合内版本从 1 逐条递增。老物件（`heritage_research_only` / `controlled_display`）默认只用于研究或受控展示，不得因演出、排练目的出库，仅限研究的老物件不得进入运输清单。个人、机构及商业敏感信息仅向履行职责所需的调用方开放。
